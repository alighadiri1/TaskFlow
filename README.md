# TaskFlow

TaskFlow is a simple and clean task management application built with
vanilla JavaScript. The goal of this project is to demonstrate solid
frontend fundamentals, including state management, UI/UX design,
and responsive layouts — without using any external libraries or frameworks.

---

## Features

- Add, edit, and delete tasks
- Mark tasks as completed with confirmation
- Filter tasks (All / Active / Done)
- Drag & drop to reorder tasks
- Persistent data storage using LocalStorage
- Dark / Light theme toggle
- Fully responsive and mobile-friendly
- Stable scroll behavior for long task lists

---

## Tech Stack

- HTML5
- CSS3 (Flexbox, Media Queries)
- Vanilla JavaScript
- LocalStorage API

---

## Responsive Design

The interface is designed to work smoothly on both desktop and mobile devices.
Layouts, modals, and interactions adapt properly to different screen sizes.

---

## How to Run

1. Clone the repository
2. Open `index.html` in your browser

No build tools or dependencies required.

---

## Notes

This project is intentionally built without frameworks to focus on
core JavaScript and CSS concepts and clean UI behavior.
